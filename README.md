## 📌 Sobre o projeto

A fraude em transações financeiras representa um dos grandes desafios do setor bancário e das instituições financeiras. Identificar operações fraudulentas de maneira eficiente é fundamental para reduzir prejuízos financeiros, aumentar a segurança das transações e proteger os consumidores.

Este projeto tem como objetivo explorar o problema de **detecção de fraudes em transações com cartão de crédito**, utilizando técnicas de análise de dados e Python para investigar padrões e identificar possíveis comportamentos fraudulentos.

O desenvolvimento foi realizado em um notebook Jupyter, permitindo acompanhar as etapas da análise e a aplicação das técnicas utilizadas.

## 🎯 Objetivos

- Explorar e compreender os dados relacionados às transações financeiras.
- Identificar possíveis padrões associados a operações fraudulentas.
- Realizar análise exploratória dos dados (EDA).
- Investigar características relevantes para a identificação de fraudes.
- Aplicar conhecimentos de Python e Ciência de Dados em um problema real do mercado financeiro.

## 🚀 Como executar o projeto

Você pode executar o projeto localmente seguindo os passos abaixo.

**1. Clone o repositório**

```bash

```

**2. Acesse a pasta do projeto**

```bash
cd Deteccao-de-fraudes-com-cartao
```

**3. Instale as dependências**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Inicie o Jupyter Notebook**

```bash
jupyter notebook
```

**5. Abra o arquivo**

```text

```

Execute as células do notebook para acompanhar o desenvolvimento da análise.
